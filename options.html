Prompt Pilot Settings

Configure automation timing, logging, download behavior and site selectors.

General

Failed-prompt retry and timeout recovery

A prompt succeeds when the visible generated-image count increases and the composer is ready for the next prompt. Terminal failures are logged and the queue advances automatically. Optional retries occur only when enabled with a positive retry count. Timing changes are saved live and apply to an active run immediately.

Safety invariant: Prompt Pilot never clicks controls labeled Stop, Cancel, Pause, Abort or Interrupt.

Docked control center

The right-side page panel can be resized directly by dragging its left edge. These defaults are used when the panel opens on a new tab.

Prompt parsing

Downloads

Downloads use the platform's native full-resolution download button first. Prompt Pilot never cancels that native download. When Chrome exposes the URL, it can additionally save a JPEG with the prompt in EXIF comments.

Site-specific behavior

Site selector configuration

Edit this JSON to add sites or tune selectors. Each config is selected by URL pattern, then the runner uses its input, submit, busy, image, download and new-chat selectors.
